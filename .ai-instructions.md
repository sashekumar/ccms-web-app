## 🚫 Absolute Prohibitions

**NEVER do these things:**

1. ❌ **Raw SQL queries** - Always use QueryBuilder
   ```typescript
   // ❌ FORBIDDEN
   await database.query('SELECT * FROM users WHERE id = ' + userId);
   
   // ✅ REQUIRED
   await this.queryBuilder.select('*').from('users').where('user_id', userId).execute();
   ```

2. ❌ **Skip MVC layers** - Never Controller → Repository directly
   ```typescript
   // ❌ FORBIDDEN
   class UserController {
     async getUser() {
       return await this.userRepository.findById(id); // NO!
     }
   }
   
   // ✅ REQUIRED
   class UserController {
     async getUser() {
       return await this.userService.findById(id); // YES!
     }
   }
   ```

3. ❌ **Ignore base classes** - Always extend BaseRepository, BaseService, BaseController

4. ❌ **Store JWT in localStorage** - Always use httpOnly cookies

5. ❌ **Create duplicate utilities** - Check existing utils first

6. ❌ **Ignore naming conventions** - Follow coding-standards.md strictly

7. ❌ **SELECT *** - Always specify columns

8. ❌ **Create N+1 queries** - Use JOINs or batch loading

## ✅ Required Patterns

### 1. Database Operations

**✅ ALWAYS use QueryBuilder for ALL queries:**

```typescript
// Read
const users = await this.queryBuilder
  .select(['user_id', 'email', 'full_name'])
  .from('users')
  .where('status', 'ACTIVE')
  .execute<User>();

// Create
const newUser = await this.queryBuilder
  .insert('users', {
    email: 'user@example.com',
    full_name: 'John Doe',
    created_at: new Date()
  })
  .execute();

// Update
await this.queryBuilder
  .update('users')
  .set({ status: 'INACTIVE' })
  .where('user_id', userId)
  .execute();

// Delete
await this.queryBuilder
  .delete('users')
  .where('user_id', userId)
  .execute();
```

### 2. MVC Layer Structure

**✅ ALWAYS follow this exact structure:**

```typescript
// 1. Entity (data model)
export interface User {
  userId: string;
  email: string;
  fullName: string;
}

// 2. Repository (database operations ONLY)
export class UserRepository extends BaseRepository<User> {
  constructor() {
    super('users', 'user_id');
  }
  
  // Custom queries here
  async findByEmail(email: string): Promise<User | null> {
    return await this.queryBuilder
      .select('*')
      .from('users')
      .where('email', email)
      .executeOne<User>();
  }
}

// 3. Service (business logic ONLY)
export class UserService extends BaseService<User> {
  constructor(private userRepository: UserRepository) {
    super(userRepository);
  }
  
  async registerUser(data: any): Promise<User> {
    // Validation, business logic, transformations
    const hashedPassword = await bcrypt.hash(data.password, 12);
    return await this.userRepository.create({
      ...data,
      password: hashedPassword
    });
  }
}

// 4. Controller (HTTP handling ONLY)
export class UserController extends BaseController {
  constructor(private userService: UserService) {
    super();
  }
  
  async register(req: Request, res: Response): Promise<void> {
    const user = await this.userService.registerUser(req.body);
    this.success(res, user, 'User registered successfully');
  }
}
```

### 3. Authentication

**✅ ALWAYS use httpOnly cookies:**

```typescript
// Login - set cookie
res.cookie('accessToken', token, {
  httpOnly: true,
  secure: process.env.NODE_ENV === 'production',
  sameSite: 'strict',
  maxAge: 15 * 60 * 1000 // 15 minutes
});

// Protected route - use middleware
router.get('/api/claims', authenticate, claimController.getAll);

// Logout - blacklist token
await tokenBlacklistService.addToBlacklist(token);
res.clearCookie('accessToken');
```

### 4. Pagination

**✅ ALWAYS use cursor-based pagination for lists:**

```typescript
async findPaginatedByCursor(cursor?: string, limit: number = 20) {
  let query = this.queryBuilder
    .select(['id', 'name', 'created_at'])
    .from('items')
    .orderBy('created_at', 'DESC')
    .limit(limit + 1);

  if (cursor) {
    const [timestamp, id] = Buffer.from(cursor, 'base64')
      .toString('utf-8')
      .split(':');
    query = query.whereLessThan('created_at', new Date(timestamp));
  }

  const results = await query.execute();
  const hasMore = results.length > limit;
  const data = hasMore ? results.slice(0, limit) : results;
  
  return { data, nextCursor: hasMore ? encodeCursor(data[data.length - 1]) : undefined, hasMore };
}
```

## 📝 Naming Conventions (Non-Negotiable)

**Apply these rules to EVERY piece of code:**

| Item | Convention | Example |
|------|-----------|---------|
| Files (all) | kebab-case | `user-profile.component.ts`, `user.service.ts` |
| Classes | PascalCase + Suffix | `UserController`, `ClaimService`, `AuthRepository` |
| Interfaces | PascalCase (I prefix optional) | `User`, `IDatabase`, `ClaimData` |
| Functions/Methods | camelCase + Verb | `getUser()`, `createClaim()`, `validateInput()` |
| Variables | camelCase | `userId`, `claimAmount`, `isActive` |
| Constants | UPPER_SNAKE_CASE | `MAX_RETRIES`, `API_TIMEOUT` |
| Database Tables | snake_case (plural) | `users`, `claims`, `claim_details` |
| Database Columns | snake_case | `user_id`, `created_at`, `full_name` |
| Observables | $ suffix | `users$`, `claims$`, `loading$` |
| Booleans | is/has/can/should | `isActive`, `hasPermission`, `canEdit` |
| Event Handlers | on/handle prefix | `onClick()`, `handleSubmit()` |

## ⚡ Performance Requirements

**ALWAYS consider these when generating code:**

1. ✅ Add indexes on foreign keys
2. ✅ Add indexes on WHERE/JOIN/ORDER BY columns
3. ✅ Select only required columns (never SELECT *)
4. ✅ Use cursor-based pagination for lists
5. ✅ Prevent N+1 queries (use JOINs or batch loading)
6. ✅ Cache reference data with Redis
7. ✅ Use connection pooling (already configured)

**N+1 Query Prevention:**

```typescript
// ❌ BAD - N+1 queries
const claims = await claimRepo.findAll();
for (const claim of claims) {
  claim.user = await userRepo.findById(claim.userId); // Query in loop!
}

// ✅ GOOD - Single JOIN query
const claimsWithUsers = await database.query(`
  SELECT c.*, u.email, u.full_name
  FROM claims c
  INNER JOIN users u ON c.user_id = u.user_id
`);

// ✅ GOOD - Batch loading
const claims = await claimRepo.findAll();
const userIds = [...new Set(claims.map(c => c.userId))];
const users = await userRepo.findByIds(userIds);
const userMap = new Map(users.map(u => [u.userId, u]));
claims.forEach(c => c.user = userMap.get(c.userId));
```

## 🔒 Security Requirements

**ALWAYS implement these security measures:**

1. ✅ Use QueryBuilder for SQL injection prevention
2. ✅ Validate all inputs with Joi validators
3. ✅ Hash passwords with bcrypt (12 rounds)
4. ✅ Store JWT in httpOnly cookies (never localStorage)
5. ✅ Add tokens to Redis blacklist on logout
6. ✅ Check blacklist in authenticate middleware
7. ✅ Use SameSite=strict on cookies
8. ✅ Enable HTTPS in production
9. ✅ Sanitize error messages (no stack traces to client)
10. ✅ Implement rate limiting on sensitive endpoints
